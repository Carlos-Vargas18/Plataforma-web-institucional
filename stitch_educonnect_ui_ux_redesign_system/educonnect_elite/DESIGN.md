## Brand & Style

This design system defines a high-end institutional and educational SaaS environment, fusing modern fintech precision with academic prestige. The visual language conveys authority, academic rigor, and fluid technological acceleration. 

### Aesthetic Direction
- **Architectural Clarity & SaaS Precision:** Crisp content planes, structured data grids, metric micro-cards, and purposeful negative space inspire trust among academic leaders, educators, and students.
- **Atmospheric Depth:** Clean contrast achieved via Deep Navy control surfaces paired against an ultra-soft cool canvas (`#F1F5FC`), accented by high-energy Electric Blue signals.
- **Tone:** Authoritative, intelligent, frictionless, and forward-looking.

## Colors

The palette leverages deep nautical bases for structure and navigation, elevated by focused electric accents for calls to action, active indicators, and high-priority metrics.

### Functional Palette Mapping
- **Canvas & Backdrops:**
  - Dashboard Base Canvas: `#F1F5FC`
  - Card & Container Surface: `#FFFFFF`
  - Deep Anchor / Brand Primary Neutral: `#07142F`
  - Sidebar & Shell Navigation Surface: `#0F1F42`
- **Brand Accents & Interaction:**
  - Primary Action / CTA: `#175CFF` (Electric Blue)
  - Secondary Interactive / Hover States: `#3B82F6` (Vibrant Blue)
  - Subtle Highlight / Active Tints: `#E0E7FF` (Light Ice)
- **Typography & Content Hierarchy:**
  - Text Primary (Headers, key figures, critical labels): `#172554`
  - Text Secondary (Descriptions, metadata, inactive items): `#64748B`
  - Text Inverse (Sidebar content, dark panels): `#FFFFFF`
- **Structural Outlines:**
  - Border Subtle: `#E2E8F0`
  - Focused / Active Border: `#BFDBFE`
- **Status & Feedback:**
  - Success: `#10B981` (Surface Tint: `#ECFDF5`)
  - Warning: `#F59E0B` (Surface Tint: `#FFFBEB`)
  - Danger: `#EF4444` (Surface Tint: `#FEF2F2`)

## Typography

The type system blends the contemporary, geometric energy of Plus Jakarta Sans for titles, headings, and data metrics with the engineered legibility of Inter for body text, lists, and dense educational interfaces.

### Application Guidelines
- **Headings & Key Figures:** Plus Jakarta Sans provides clean tracking and strong baseline stability. Use weight `600` for mid-level UI cards and `700` for page titles and high-impact analytics metrics.
- **Tabular Data & Body:** Inter handles administrative data tables, student records, and long-form feedback. Keep body narrative at weight `400` and metric subheaders or key-value pairs at weight `500`.
- **Labels & Micro-UI:** Micro-labels use uppercase tracking (`letter-spacing: 0.04em`) at weight `600` for badges, tags, and column headers.

## Layout & Spacing

The interface employs a responsive fluid grid optimized for expansive institutional dashboards and granular micro-interactions.

### Grid & Breakpoints
- **Desktop (1280px and above):** 12-column fluid grid, 280px fixed navigation sidebar, `2rem` outer layout margin, and `1.5rem` gutter gap.
- **Tablet (768px – 1279px):** 8-column layout, collapsable icon sidebar, `1.5rem` outer margins, `1rem` column gutters.
- **Mobile (below 768px):** 4-column layout, bottom sheet navigation or top app bar, `1rem` outer margins, `0.75rem` column gutters.

### Component Spacing Rhythm
- **Internal Card Padding:** Compact metric cards use `space-md` (`1rem`); expansive analytical charts and student rosters use `space-lg` (`1.5rem`).
- **Vertical Hierarchy:** Distinct dashboard sections separate via `space-xl` (`2rem`). Related form inputs or inline metric elements group tightly with `space-sm` (`0.5rem`).

## Elevation & Depth

Visual hierarchy uses soft, multi-layered diffuse shadows combined with hairline borders to emulate high-end financial SaaS and modern dashboard software.

### Elevation Hierarchy
- **Level 0 (Flat / Canvas):** Surface color `#F1F5FC`. Used exclusively as the root backdrop.
- **Level 1 (Cards, Metric Tiles, Table Wrappers):**
  - Background: `#FFFFFF`
  - Border: `1px solid #E2E8F0`
  - Shadow: `0 1px 3px 0 rgba(7, 20, 47, 0.04), 0 1px 2px -1px rgba(7, 20, 47, 0.02)`
- **Level 2 (Hover States, Interactive Dropdowns, Tooltips):**
  - Background: `#FFFFFF`
  - Border: `1px solid #E2E8F0`
  - Shadow: `0 10px 15px -3px rgba(7, 20, 47, 0.06), 0 4px 6px -4px rgba(7, 20, 47, 0.03)`
- **Level 3 (Modals, Overlays, Slide-overs):**
  - Background: `#FFFFFF`
  - Border: `1px solid rgba(226, 232, 240, 0.8)`
  - Shadow: `0 20px 25px -5px rgba(7, 20, 47, 0.1), 0 8px 10px -6px rgba(7, 20, 47, 0.04)`

### Dark Surface Elevation (Sidebar & Institutional Shell)
- Dark surfaces use `#0F1F42` with an ambient inset border: `inset -1px 0 0 0 rgba(255, 255, 255, 0.06)` instead of drop shadows to provide crisp separation from light canvas content.

## Shapes

The design uses an approachable yet disciplined curvature scale to communicate modern luxury without sacrificing data density.

### Shape Scale
- **Base Rounding (`rounded-md` - 0.5rem / 8px):** Standard buttons, text input fields, selection tags, and badges.
- **Card Rounding (`rounded-xl` - 1rem / 16px):** Metric panels, dashboard widgets, data tables, and inline banners.
- **Container Rounding (`rounded-2xl` - 1.5rem / 24px):** Modals, major interface segments, and master shell containers.
- **Pill Rounding (`rounded-full` - 9999px):** Avatar holders, pill navigation indicators, counter badges, and status pills.

## Components

### Buttons
- **Primary:** Background `#175CFF`, text `#FFFFFF`, font weight 600, border radius `0.5rem`. Hover state transitions to `#3B82F6` with subtle ambient glow (`0 4px 14px 0 rgba(23, 92, 255, 0.35)`). Active state applies a `0.98` scale transform.
- **Secondary:** Background `#FFFFFF`, text `#172554`, border `1px solid #E2E8F0`. Hover uses `#F1F5FC` and border `#CBD5E1`.
- **Ghost / Dark Sidebar Action:** Background transparent, text `#94A3B8`. Hover background `rgba(255, 255, 255, 0.06)` with text `#FFFFFF`.

### Chips & Badges
- **Status Badges:** Compact footprint with `0.25rem` vertical and `0.625rem` horizontal padding, text size `11px`, font weight 600, rounded full (`rounded-full`).
  - Active/Success: Background `#ECFDF5`, text `#065F46`, left accent dot `#10B981`.
  - Pending/Warning: Background `#FFFBEB`, text `#92400E`, left accent dot `#F59E0B`.
  - Inactive/Critical: Background `#FEF2F2`, text `#991B1B`, left accent dot `#EF4444`.
- **Counter Badges:** Circular or pill-shaped, background `#175CFF`, text `#FFFFFF`, minimum width `18px`, height `18px`, centered text at 11px font size.

### Form Inputs & Selectors
- **Text Inputs:** Background `#FFFFFF`, border `1px solid #E2E8F0`, height `42px`, padding `0 0.875rem`, text `#172554`, placeholder `#94A3B8`, border radius `0.5rem`.
- **Focus State:** Border color `#175CFF`, box-shadow `0 0 0 3px rgba(23, 92, 255, 0.15)`, smooth transition of 150ms.
- **Checkboxes & Radios:** Size `18px x 18px`, border `1.5px solid #CBD5E1`. Checked state uses background `#175CFF`, border `#175CFF`, with a crisp white checkmark icon.

### Cards & Micro-Panels (SaaS / Fintech Style)
- **Metric Cards:** White surface (`#FFFFFF`), border `1px solid #E2E8F0`, padding `1.25rem`, border radius `1rem`. Top row aligns a light ice icon container (`#E0E7FF`, 40x40px, rounded-lg) with an optional trend chip (+12.5%). Bottom row pairs a display metric (`metric-display`, `#172554`) with an Inter subtext descriptor (`#64748B`).
- **Roster & Data Lists:** Flat horizontal division with rows divided by `1px solid #F1F5FC`. Hovering over any row initiates background color `#F8FAFC` transition.

### Navigation Shell & Active Indicators
- **Sidebar Elements:** Contained inside dark slate (`#0F1F42`). Items have height `44px`, horizontal padding `0.75rem`, font weight 500, text `#94A3B8`.
- **Active Navigation State:** Pill style with background `rgba(23, 92, 255, 0.15)`, text `#FFFFFF`, font weight 600. A vertical active accent bar (width 3px, color `#175CFF`, rounded edges) is docked to the far left of the item.

### Iconography
- Consistent stroke width of 1.75px, geometry aligned to a 20px or 24px bounding box. Primary actions and active navigational icons utilize `#175CFF` or `#FFFFFF`; muted contexts use `#64748B`.
